# StudioFlow AI 0.7 — First Video Demo

هذه نسخة تجريبية تعمل بدون API Key.
- اكتب فكرة.
- اضغط "اعمل أول فيديو".
- المنصة تحاكي مراحل الإنتاج.
- في النهاية تعرض ملف MP4 حقيقي مولّد مسبقًا داخل المشروع.

الهدف: اختبار تجربة المستخدم قبل ربط Veo الحقيقي.

تشغيل:
1. Node.js 18+
2. npm install
3. npm start
4. افتح http://localhost:3000

بعد نجاح الاختبار نبدّل Demo Generator بـ Google Veo API، ثم نضيف TTS + FFmpeg + التعديلات الطبيعية.
